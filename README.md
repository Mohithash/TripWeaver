# Trip Weaver

**Trips, woven for you.** A bring‑your‑own‑key AI travel planner.

- 🗺️ **Itinerary** — day‑by‑day plans grouped by neighbourhood so you don't zig‑zag, with times, details, areas and cost hints; a local food tip per day.
- 🔁 **Redo a day** — "more relaxed", "rainy‑day plan", "kid‑friendly" — one day regenerated, the rest untouched.
- 🎒 **Packing list** — season‑ and activity‑aware, tick items off with a progress bar.
- 💡 **Tips & phrases** — transport, money, etiquette, booking‑ahead; six local phrases.
- 💬 **Ask** — an honest assistant that says when it isn't sure.

BYOK: Claude (Anthropic) or any OpenAI‑compatible endpoint. See [PRIVACY.md](PRIVACY.md).
